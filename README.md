# Git Shell Admin Übung Justin

In diesem Projekt wurden mehrere Shell-Skripte für typische Administrationsaufgaben unter Linux erstellt.

## Skripte

- `systeminfo.sh` zeigt Systeminformationen an.
- `dateipruefung.sh` prüft, ob eine Datei oder ein Pfad existiert.
- `projektstruktur.sh` erstellt automatisch eine einfache Projektstruktur.
- `admin-menu.sh` zeigt ein kleines Terminal-Menü.

## Skripte starten

```bash
./scripts/systeminfo.sh
./scripts/dateipruefung.sh
./scripts/projektstruktur.sh
./scripts/admin-menu.sh
